# Delivery status / v0.2.1-en

Delivered locally: a standalone English HTML game, English source and documentation, fresh test results and screenshots of the running implementation.

The playable file inside the source package is `dist/NEMESIS-PACT.html`. The user-facing copy is `NEMESIS-PACT-Mobile-EN-v0.2.1.html`; their bytes match.

The Japanese v0.2.0 source archive was used as the baseline, without overwriting the separately delivered Japanese files. This edition does not include a runtime language toggle.

No GitHub write, push or remote-state check was performed in this localization task. The previously intended repository is `Yasei-no-otoko/openai-100-hour-game-builder-challenge`; this document makes no claim about its current contents.

Tests and limitations are in [TESTING.md](TESTING.md). A controlled boss screenshot is a rendering fixture, not evidence of human gameplay or a real-device test. Direct file navigation was blocked by managed browser policy, so offline browser tests loaded the exact distribution HTML in memory instead.
