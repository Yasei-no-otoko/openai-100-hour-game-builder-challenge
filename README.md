# BLAST BUSTER: NEMESIS PACT

**約束を武器に、弾幕を返せ。**

OpenAI: 100-Hour Game Builder Challenge 向けゲームの初回プレイアブル版です。**OpenAI APIを含む外部API、ネット接続、モデル、アカウント、ランタイムの追加インストールは不要**です。ゲーム内容はすべてローカルで実行します。

敵と結んだ契約が、その領域の戦闘ルールを変えるアリーナシューティング。弾を遅くする代わりに数が増える。反射を強める代わりに通常射撃が弱まる。約束を守って勝つか、窮地で破って生き延びるか。

## すぐ遊ぶ

`dist/NEMESIS-PACT.html` をダウンロードして、デスクトップブラウザで開いてください。**単一HTMLファイルにゲーム・描画・音楽・UIを収録**しています。GitHubのファイル表示画面そのものではプレイできません。ソース一式をダウンロードする場合はZIPを展開してから開いてください。

最初は「操作を試す」→「出撃する」→ STORY を推奨。1周は自動プレイ計測で約4分ですが、人間の所要時間は腕前・ビルド・選択時間で変わります。これはネイティブの `.exe` / `.app` ではなく、オフラインのブラウザゲームです。

## 操作

| 操作 | キー |
|---|---|
| 移動 | WASD / 矢印キー |
| 照準・射撃 | マウス / 左クリック長押し |
| キーボードのみで射撃 | J 長押し（自動照準） |
| 無敵ダッシュ | SPACE / SHIFT |
| 敵弾を反射するパリィ | E / 右クリック |
| スーパーノヴァ | F |
| 契約破棄（領域ごとに1回） | Q |
| 契約・強化選択 | 1 / 2 / 3、またはクリック |
| 一時停止 / ミュート | ESC / M |

発動直後0.105秒のパリィは強力なジャスト反射。グレイズ・反射・撃破でエネルギーを溜め、ノヴァで弾幕とレーザーを一掃できます。レーザーはパリィできません。機体中央の白い点が敵弾に対する当たり判定です。

標準配置ゲームパッド入力も実装していますが、実機検証は未実施です。設定に自動射撃、照準補助、演出軽減、音量・音楽切り替えがあります。フォーカスを失うと自動停止します。

## 収録内容

3領域 ×（前哨戦2回＋ボス戦）、5種の通常敵、3体の3フェーズボス、7種類の契約、13種類の強化選択肢、3難易度、訓練モード。契約を守る／一部破る／すべて破る行動で結末が変わります。

各領域では3つの契約候補から1つ選び、前哨戦を終えるごとに強化を選びます。強化は1周の間持続し、一部は重ねて取得可能。領域突破時にはHPが2回復します。ゲームオーバー後は同じシードで再挑戦できます。

シードは敵の出現計画と強化候補の抽選を固定します。ただし取得済み強化・HPによる候補の変化、プレイヤー近くの出現回避などはゲーム状態に依存します。「本日のシード」は端末の日付に基づくローカル機能で、オンラインランキングではありません。

スコア上位12件と設定をブラウザ内に保存し、リザルトをJSONで書き出せます。ストレージが拒否される環境では保存なしで続行します。**ラン途中からの再開や、入力を再生するリプレイ機能はありません。**

## 開発・検証

Node.js 18以降。ゲーム本体にnpm依存パッケージはありません。

```sh
npm run check
npm run build
npm test
node tests/simulate.js
npm start
```

`npm start` は任意のローカル開発サーバーです。配布HTMLを遊ぶだけならNode.jsもサーバーも不要です。

ブラウザ検証にはテスト用のPython PlaywrightとChromiumが必要です。実行環境に用意したうえで次を実行します。

```sh
python3 tests/browser_test.py --browser /path/to/chromium
```

28件の自動テスト、9条件の合法入力ボットによる完走、ブラウザ内の完走・画面遷移・JSON出力を検証しました。正確な範囲と未検証項目は [docs/TESTING.md](docs/TESTING.md) を参照してください。**自動テストは「GOTY級の面白さ」の証明ではありません。人間による初見プレイ・継続意欲・難易度評価はこれから必要です。**

## 構成

```text
index.html                  開発用エントリーポイント
src/core.js                 DOM非依存の決定的な戦闘シミュレーション
src/game.js                 Canvas描画・画面・入力・ローカル保存
src/audio.js                Web Audioによる音楽・効果音の生成
src/style.css               UIスタイル
tools/build.js              依存なしの単一HTMLビルダー
tools/serve.js              任意のローカルサーバー
tests/core.test.js          ルール・進行・衝突・再現性のテスト
tests/simulate.js           合法入力による完走検証
tests/browser_test.py      オフラインのブラウザ検証
dist/NEMESIS-PACT.html       配布用・単独起動ファイル
docs/                       設計・検証の記録
```

アートはCanvasで、音楽と効果音はWeb Audioで生成します。CDN、外部フォント、画像・音声素材、分析SDK、秘密鍵は含みません。AI連携は未実装で、ゲームの成立に必要ありません。
