## 未検証・制限

この実行環境ではブラウザ管理ポリシーがfile URLとlocalhostへのナビゲーションを禁止しているため、ファイルのダブルクリック起動は直接検証していません。ポリシーは変更せず、同一の自己完結HTMLをabout:blankにロードして検証しました。

about:blankではストレージ拒否時のフォールバックを検証。実際のfile URLでの設定・ハイスコアの再読み込みは未検証です。ブラウザ・プライバシー設定によって保存できない場合があります。

Safari / Firefox / Windows / macOS実機、ゲームパッド実機、スマートフォン操作、主観的な音質・ラウドネス、長時間の性能、人間による面白さ・アクセシビリティの評価は未実施。ネイティブアプリ・タッチ専用UI・オンラインランキング・途中セーブは収録しません。

## 再実行

```sh
npm run check
npm run build
npm test
npm run test:simulation
python3 tests/browser_test.py --browser /path/to/chromium
```

ブラウザテストには別途Python Playwrightが必要です。ゲーム本体には不要です。テスト用状態公開は `?test=1` または検証ハーネスが設定するフラグでのみ有効です。
