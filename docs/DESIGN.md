# NEMESIS PACT / Design notes

## 核となる問い

「戦う前に、戦い方を相手と決められたら？」

交渉は長い会話ではなく、利益と代償が明示された選択。戦闘で条件を体験させ、Qによる破棄で約束を守るか生存を優先するかを判断させる。最終的なゲームルールは有限で、確定的で、プレイヤーに説明可能にする。

## 1周の構造

契約 → 前哨戦I → 強化 → 前哨戦II → 強化 → ボス。これを3領域繰り返す。難所を越えるたびに報酬があり、ボス撃破後に回復。死亡すると最初からだが、同じシードでリトライ可能。周回外の恒久強化は設けず、成長を操作の習熟とビルド選択へ寄せる。

## スキル表現

射撃だけでなく、敵弾を利用して攻撃する。パリィは0.23秒、最初の0.105秒はジャスト反射。敵弾が密集した時ほど反射とエネルギー獲得に価値が生まれる。ダッシュはパリィ不能なレーザーへの対処、ノヴァは画面一掃、破棄は1領域に一度の強い緊急策として区別する。

## 契約

| 契約 | 利益 | 代償 |
|---|---|---|
| 慈悲の速度 | 敵弾速度0.7倍 | 通常弾の発射時に40%の確率で追加1発 |
| 鏡の報復 | 反射威力2.2倍 | 通常射撃威力0.75倍 |
| 硝子の決闘 | 敵HP0.7倍 | 被ダメージ2倍 |
| 沈黙の条項 | 5秒周期の最後1.3秒、敵弾停止 | 自分も射撃不可 |
| 一対一の誓い | ボス増援なし | ボス攻撃頻度1.25倍 |
| 聖域の条件 | 中央半径76内で敵弾消滅 | 通常射撃威力0.78倍 |
| 加速の代償 | ダッシュ再使用0.55倍 | 敵弾速度1.3倍 |

破棄すると双方の条件を解除し、敵の攻撃頻度が1.25倍になる。その場では敵弾・レーザー消去、HP+1、2秒の無敵と敵の停止、ボス最大HP20%／通常敵100のダメージ。出現予告中の敵にはダメージを与えない。破棄する時点で硝子の敵HPスケールも解除する。

## 実装上の分離

`core.js` は入力状態と固定時間刻みを受け、ルールを更新し、出来事をイベントとして返す。Canvas、音声、ローカル保存は参照しない。`game.js` が実時間から120Hzの固定更新へ変換し、イベントに画面・音を付ける。疑似乱数はゲームロジック用と装飾用を分離。出現計画と強化抽選も別のシード列にする。

外部APIを後から検討する場合も、契約IDと有限のルールへの変換境界を維持する。自由文やネット応答を直接コード実行・戦闘判定へ渡す構造にはしない。現版には推論SDK、AIコード、キー設定は存在しない。

## 次の判断に必要なプレイテスト

初見でパリィを自発的に使えるか。契約の代償を読めるか。破棄を忘れず意図して使えるか。最初の敗北の直後にもう一度始めるか。実機でマウス／ゲームパッドの照準が気持ちよいか。GOTY水準を目指す際には、これらの人間による検証と、ボス・ビルドの独自性をさらに掘り下げる必要がある。
